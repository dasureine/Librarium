# 项目永久规范

## 视觉配色

全站与所有知识地图只能使用黑、白、灰、绿四种色系，严禁出现蓝、紫、红、黄等其他彩色，保持学术极简风格。

- 页面背景：#F7F8F7
- 卡片：#FFFFFF
- 主文字：#1A1A1A
- 次要文字：#595959
- 边框：#D8DDD8
- 主题强调绿：#1F4E3D
- 辅助浅绿：#EBF2EE / #4A7C62

## 技术约束

纯静态单文件 HTML（原生 HTML/CSS/JS/SVG），严禁引入任何外部 CDN 资源或构建工具，离线可用。

## 数据分离

每张知识地图（maps/*.html）把全书节点、连线、视角与步进数据统一放在 script 顶部的 `const MAP_DATA = { ... };` 中，渲染逻辑与数据解耦；左上角保留指向 `../index.html` 的返回链接。

## 增量红线

以后根据新笔记添加新书地图时，只允许新建 `maps/新书.html` 并在 `books.json` 末尾追加条目，严禁重写或修改 `index.html`、`templates/map-template.html` 及已有的其他地图文件。

## 文本风格

忠于原始笔记，使用简单平和的书面中文，主谓宾结构，去掉口语化寒暄、比喻、总结套话、防御性表述和“不是……而是……”句式。

##硬性红线

打开项目根目录下的 .clinerules 文件，在里面加上一条硬性红线：notes/ 目录下的所有 .md 文件属于用户的只读原稿，任何情况下严禁修改、覆盖或重写 notes/*.md。
