# 大部头电子书精读笔记标准流程

请严格遵守项目规则，按以下顺序执行。

## 0. 准备工作

- 拆分原文：运行 `python scripts/split_book.py <电子书路径> [--name 英文书名缩写] [--level 目录层级] [--map 页码映射文件]`。
  - 脚本会在 `workspace/<书名缩写>/chapters/` 生成各章纯文本，并自动创建 `chapter_notes/` 与空的 `glossary.md`。
  - 若电子书无内嵌目录，脚本会生成 `workspace/<书名缩写>/pages_map.txt`，按提示填写后以 `--map` 指向该文件重新运行。
  - 若脚本提示「疑似纯图片扫描版 PDF」，先完成 OCR 转换后再继续。

## 1. 分批推进机制

- 每次仅处理用户指定的 2-3 个章节。
- 从 `workspace/<书名>/chapters/` 读取对应编号与章名的原文。
- 逐章输出到 `workspace/<书名>/chapter_notes/<同编号与章名>.md`。
- 严禁跳章、敷衍缩写或修改已完成的历史章节。

## 2. 跨章概念锚点

- 动笔前必须先读取 `workspace/<书名>/glossary.md`。
- 每写完一章，立即向 `glossary.md` 追加 3-5 条本章的核心概念、专有译名及核心命题推进。
- 确保跨任务续读时术语与主线统一。

## 3. 写作规范

以下文风红线对所有单章笔记与全书总览强制生效，必须逐条遵守：

- 严格对齐 `notes/rujiao-daojiao.md` 的文风与论证拆解颗粒度：平实、精准的学术陈述句，严禁抒情评价与空洞套话。
- 去掉无意义的假口语化、比喻和套话式总结。
- 改掉「不是……而是……」句式。
- 使用符合中文习惯的直接主谓宾陈述句。
- 去掉内容的同义重复与防御性表述（如「需要指出的是」「不可否认」「在某种程度上」等）。
- 每章笔记固定包含四部分结构：
  - 核心问题意识
  - 论证结构与推进
  - 关键概念界定
  - 章节衔接与张力

## 4. 总览与合并模式

当用户指示「生成全书总览并合并」时：

1. 读取 `workspace/<书名>/glossary.md` 及各章笔记的小节标题。
2. 撰写 `workspace/<书名>/overview.md`（全书核心问题、逻辑框架与章节脉络）。
3. 运行 `python scripts/merge_notes.py <书名缩写> [--title "书名"]` 生成最终的 `notes/<书名缩写>.md`。

## 5. 红线

- 严禁修改 `index.html`、`books.json`、`templates/`、`maps/` 及 `notes/` 下已有的文件。
- `notes/` 下的 `.md` 文件为用户只读原稿，任何情况下严禁修改、覆盖或重写。
